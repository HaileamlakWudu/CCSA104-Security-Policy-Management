\## 1. Project Overview



This repository contains my completed practical assignment for \*\*CCSA104 – Security Policy Management\*\*, part of the Check Point Certified Security Administrator (CCSA) training program at the International Cybersecurity and Digital Forensics Academy.



The assignment focuses on the practical application of Check Point Security Policy Management using SmartConsole. It demonstrates the fundamental concepts and procedures involved in creating, organizing, managing, publishing, installing, and verifying network security policies.



The practical exercises are based on Lab 4A: \*Manage the Security Policies\*.



\## 2. Assignment Objectives



The main objectives of this assignment were to demonstrate an understanding of:



\- Security Policies and the Positive Control (whitelist) security model.

\- Creating and managing Access Control rulebases.

\- Configuring Stealth and Cleanup rules.

\- Organizing security policies using sections.

\- Understanding and configuring security zones.

\- Configuring Hide Network Address Translation (Hide NAT).

\- Publishing and installing security policies.

\- Verifying policy behavior through logs.

\- Managing Global Properties and Policy Packages.

\- Reviewing Installation History.
